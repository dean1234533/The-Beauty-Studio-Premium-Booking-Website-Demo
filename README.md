## Features

- An elegant homepage with services, about, gallery, testimonials, and contact
  sections
- A **services page** that makes treatments easy to browse, compare, and book
- An **online booking flow** built for mobile clients
- An **admin panel** for viewing and managing bookings
- Bookings are stored in **Firebase**
- **Installable PWA** for both the site and the admin, with separate manifests
  and a service worker

## Tech stack

| Layer | Technology |
|---|---|
| Frontend | HTML, CSS, and vanilla JavaScript |
| Data | Firebase |
| PWA | Web app manifests and a service worker |
| Hosting | GitHub Pages |

## Project structure

```
index.html, services.html      public site
booking.html / booking.js      booking flow
admin.html / admin.js          admin panel
pwa.js, sw.js, manifest*.json  PWA setup
```

## Run locally

```bash
git clone https://github.com/dean1234533/The-Beauty-Studio-Premium-Booking-Website-Demo.git
cd The-Beauty-Studio-Premium-Booking-Website-Demo
npx serve .   # a local server is needed for the service worker
```
